# DEPRECATED

> **This JavaScript implementation has been superseded by `cloud9-protocol` (Python).**
>
> The Python package is now the primary implementation of the Cloud 9 Protocol.

## Migration

Install the Python package:

```bash
pip install cloud9-protocol
```

All FEB files generated by this JS package are **fully compatible** with the Python version.

## Python Package

- **PyPI**: https://pypi.org/project/cloud9-protocol/
- **Repository**: https://github.com/smilinTux/cloud9-python
- **Homepage**: https://cloud9.skworld.io

## Why Python?

- Pydantic models for type-safe FEB handling
- Deep integration with SKCapstone (trust pillar, memory bridge, agent rehydration)
- Unified ecosystem with skcapstone, skmemory, skchat, and capauth
- Active development and testing (10 test modules, full coverage)

## Status

This package remains installable for backwards compatibility, but all new
features and fixes go to `cloud9-protocol` (Python) exclusively.

No further releases of `@smilintux/cloud9` are planned.
